# Loan Approval Workflow

The loan approval workflow starts when the customer submits an application and ends when the bank records a final credit decision.

## Workflow stages

1. Application submitted.
2. Required documents uploaded.
3. Documents verified by an admin reviewer.
4. Eligibility and risk score reviewed.
5. Credit decision recorded.
6. Customer receives approval, rejection, or request for more information.

## Pending applications

An application may remain pending if documents are missing, verification has not been completed, risk needs manual review, or the credit decision has not yet been recorded.
