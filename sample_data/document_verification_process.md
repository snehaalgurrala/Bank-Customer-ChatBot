# Document Verification Process

Document verification checks whether uploaded files are complete, readable, current, and consistent with the application.

## Verification steps

1. Confirm the file opens and is not password-protected.
2. Check that the customer name and key details match the application.
3. Validate that income proof and bank statements cover the requested period.
4. Mark the document as verified, rejected, or needs resubmission.

## After verification

When all required documents are verified, the application can proceed to credit decisioning. If any document is rejected or unclear, the customer should upload a corrected file.
